# Requisitos no funcionales

Los 14 RNF de la sección de Requisitos del documento académico (Fase de
Análisis, cerrada). Consultar antes de resolver algo transversal a varios
subsistemas: seguridad, rendimiento, disponibilidad, compatibilidad de
navegadores, etc.

| ID | Requisito no funcional | Descripción |
|---|---|---|
| RNF-01 | Seguridad | El sistema deberá proteger el acceso a las funcionalidades mediante mecanismos de autenticación y autorización de acuerdo con el rol del usuario. |
| RNF-02 | Protección de credenciales | El sistema deberá almacenar las credenciales de los usuarios de forma segura, evitando conservar las contraseñas en texto plano. |
| RNF-03 | Protección de datos | El sistema deberá proteger la información personal y de las operaciones registradas frente a accesos no autorizados. |
| RNF-04 | Integridad de datos | El sistema deberá garantizar la consistencia e integridad de la información relacionada con usuarios, eventos, entradas, compras y accesos. |
| RNF-05 | Rendimiento | El sistema deberá proporcionar tiempos de respuesta adecuados durante las operaciones habituales de consulta, gestión y compra. |
| RNF-06 | Disponibilidad | El sistema deberá encontrarse disponible para la consulta y adquisición de entradas durante los períodos establecidos para la venta. |
| RNF-07 | Usabilidad | La interfaz deberá permitir a los usuarios comprender y completar las operaciones disponibles de manera clara e intuitiva. |
| RNF-08 | Diseño adaptable | La interfaz deberá adaptarse correctamente a diferentes tamaños de pantalla de computadoras y dispositivos móviles. |
| RNF-09 | Compatibilidad | La aplicación web deberá funcionar correctamente en los principales navegadores web actuales. |
| RNF-10 | Mantenibilidad | El sistema deberá utilizar una estructura organizada que facilite su mantenimiento, corrección y evolución. |
| RNF-11 | Escalabilidad | El sistema deberá permitir incorporar nuevos eventos, usuarios y funcionalidades sin requerir una modificación completa de la arquitectura existente. |
| RNF-12 | Interoperabilidad | El sistema deberá permitir la comunicación e intercambio de información entre sus diferentes componentes y servicios de manera estructurada. |
| RNF-13 | Respaldo y recuperación | La información almacenada deberá contar con mecanismos de respaldo que permitan su recuperación ante posibles fallos. |
| RNF-14 | Trazabilidad de operaciones | El sistema deberá conservar registros de las operaciones relevantes realizadas sobre entradas, accesos, compras y devoluciones. |
